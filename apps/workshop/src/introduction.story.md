# Welcome

Duskit is made for Dusk, it embodies the ethos of the Dusk community, serving as a set of guidelines comprising open-source principles, standards, and recommendations tailored for designing Dusk applications. As a comprehensive design language, Duskit furnishes a shared grammar and lexicon, facilitating the creation of unified, accessible, responsive, and streamlined user experiences.

### Design Tokens

Duskit uses design tokens to deliver color, font, size and time information to the UI. Duskit represents color design tokens as CSS variables for development and Figma design tokens for design work, respectively.

#### Naming Convention

Design tokens in Duskit follow the same "category/type/item" structured naming conventions as outlined in [StyleDictionary](https://amzn.github.io/style-dictionary/#/tokens?id=category-type-item).
